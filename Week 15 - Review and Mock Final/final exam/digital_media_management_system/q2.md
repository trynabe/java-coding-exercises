# 📘 Digital Media Management System (Polymorphism, Interface, List)

## 📁 Files to Create

* Media.java
* Song.java
* Movie.java
* Podcast.java
* Playlist.java

---

## 🔹 Task 1: Create Interfaces and Classes

### ✅ Interface: Media (in `Media.java`)

Methods:

* `String getTitle()`
* `int getDuration()` (unit: minutes)

### ✅ Interface: Playable (in `Media.java`)

Methods:

* `void play()`

---

### ✅ Class: Song (in `Song.java`)

Implements: `Media`, `Playable`

Attributes:

* `String title`
* `int duration`
* `String artist`
* `String genre`

Behavior:

* `play()` → Display:

```
Now playing: [title] by [artist]
```

---

### ✅ Class: Movie (in `Movie.java`)

Implements: `Media`, `Playable`

Attributes:

* `String title`
* `int duration`
* `String director`
* `double rating`

Behavior:

* `play()` → Display:

```
Now playing: [title] by [director]
```

---

### ✅ Class: Podcast (in `Podcast.java`)

Implements: `Media`, `Playable`

Attributes:

* `String title`
* `int duration`
* `String host`
* `String topic`

Behavior:

* `play()` → Display:

```
Now playing: [title] by [host]
```

---

## 🔹 Task 2: Create Class Playlist (in `Playlist.java`)

### Attributes:

* `List<Media> mediaList`

### Methods:

* `void addMedia(Media media)` → Add media to list
* `int getTotalDuration()` → Return total duration of all media
* `void playAll()` → Call `play()` for each media in list

---

## 🔹 Task 3: Main Method (in `Playlist.java`)

### Steps:

1. Create objects of:

   * Song
   * Movie
   * Podcast
2. Create Playlist object
3. Add all media into Playlist
4. Call:

   * `getTotalDuration()`
   * `playAll()`

## 📌 Notes

* Use `ArrayList` for storing media
* Apply **Polymorphism** when storing objects in `List<Media>`
* Each class must implement all required methods from interfaces
