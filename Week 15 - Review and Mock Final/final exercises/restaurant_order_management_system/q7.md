# 📝 ข้อ 7: ระบบร้านอาหารและยอดขาย (Restaurant Order System)

📌 **รายละเอียดโจทย์**
ร้านอาหารแห่งหนึ่งมีเมนูหลายประเภท เช่น อาหารไทย, อาหารญี่ปุ่น, และอาหารเกาหลี ทางร้านต้องการระบบคำนวณยอดขายรวม โดยพิจารณาจาก `ราคาสินค้า × จำนวน` 
🎁 **โปรโมชันพิเศษ:** หากลูกค้าซื้อเมนูใดเมนูหนึ่ง **เกิน 3 ชิ้นขึ้นไป** จะได้รับส่วนลด **10%** สำหรับเมนูนั้น

---

### 📁 ไฟล์และคลาสที่ต้องสร้าง
1. `MenuItem.java` (Abstract Class)
2. `ThaiFood.java` (Subclass)
3. `JapaneseFood.java` (Subclass)
4. `KoreanFood.java` (Subclass)
5. `RestaurantOrder.java` (Main Class)

---

### 🎯 สิ่งที่คุณต้องทำ (Tasks)

1. **สร้าง Abstract Class `MenuItem`:**
   * มี Attribute: `String name`, `double price`
   * มี Abstract Method: `double calculateDiscountedPrice(int quantity)`

2. **สร้าง Subclass (`ThaiFood`, `JapaneseFood`, `KoreanFood`):**
   * สืบทอดจาก `MenuItem`
   * Implements เมธอด `calculateDiscountedPrice(int quantity)`
   * 🔄 **บังคับใช้ Recursion:** ในการคำนวณราคารวมของเมนูก่อนหักส่วนลด 
   * หาก `quantity > 3` ให้ลดราคาลง 10% จากราคารวมของเมนูนั้น

3. **สร้าง Main Class `RestaurantOrder`:**
   * ใช้ `Map<String, List<MenuItem>>` เพื่อจัดกลุ่มเมนูตามประเภท
   * ใช้ `Map<MenuItem, Integer>` เพื่อเก็บรายการเมนูและจำนวนที่ลูกค้าสั่ง
   * สร้างเมธอด `double calculateTotalSales(Map<MenuItem, Integer> order)` เพื่อคำนวณยอดสุทธิหลังหักส่วนลดทั้งหมด
   * แสดงสรุปรายการอาหาร (Order Summary) และยอดรวม (Total sales)
