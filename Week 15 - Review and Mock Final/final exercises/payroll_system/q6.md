# 📝 ข้อ 6: ระบบคำนวณค่าจ้างพนักงานพาร์ทไทม์ (Part-time Employee Payroll System)

📌 **รายละเอียดโจทย์**
บริษัทแห่งหนึ่งต้องการระบบคำนวณค่าจ้างสำหรับพนักงานพาร์ทไทม์ 2 ประเภท ได้แก่ **พนักงานรายชั่วโมง** และ **พนักงานรายวัน** ซึ่งมีอัตราการคำนวณค่าจ้างที่แตกต่างกัน นอกจากนี้ ระบบจะต้องสามารถจัดการกับข้อผิดพลาด (Exception) ได้ในกรณีที่ผู้ใช้ป้อนค่าเวลาทำงานเป็นตัวเลขติดลบหรือศูนย์

---

### 📁 ไฟล์และคลาสที่ต้องสร้าง
1. `Payable.java` (Interface)
2. `HourlyEmployee.java` (Class)
3. `DailyEmployee.java` (Class)
4. `PayrollSystem.java` (Class สำหรับรันโปรแกรม)

---

### 🎯 สิ่งที่คุณต้องทำ (Tasks)

1. **สร้าง Interface `Payable`:**
   * กำหนดเมธอด `double calculatePay()`

2. **สร้าง Class `HourlyEmployee`:**
   * ให้ `implements Payable`
   * **สูตรคำนวณค่าจ้าง:** `hours × 120`

3. **สร้าง Class `DailyEmployee`:**
   * ให้ `implements Payable`
   * **สูตรคำนวณค่าจ้าง:** `days × 600`

4. **การจัดการข้อผิดพลาด (Exception Handling):**
   * ในคลาส `HourlyEmployee` และ `DailyEmployee` หากค่าที่รับเข้ามา (ชั่วโมง หรือ วัน) มีค่า **น้อยกว่าหรือเท่ากับ 0** ให้ทำการโยน Exception ด้วยคำสั่ง: 
     `throw new IllegalArgumentException("จำนวนต้องมากกว่าศูนย์");`

5. **สร้าง Class `PayrollSystem` (Main):**
   * เขียนเมธอด `main()` เพื่อรับประเภทพนักงานและเวลาทำงานจากผู้ใช้
   * ใช้ `try-catch` เพื่อแสดงผลรวมค่าจ้าง หรือแสดงข้อความ Error หากเกิด Exception
