## 📁 Files to Create

* Schedule.java
* YogaClass.java
* ZumbaClass.java
* BoxingClass.java
* Member.java
* FitnessSchedule.java

## 🔹 Task 1: Interface & Classes

### ✅ Interface: Schedule (in `Schedule.java`)

Methods:

* `String getTime()` → e.g. "10:00 AM"
* `String getDay()` → e.g. "Monday"

---

### ✅ Class: YogaClass (in `YogaClass.java`)

Implements: `Schedule`

Attributes:

* `String day`
* `String time`
* `String instructor`

---

### ✅ Class: ZumbaClass (in `ZumbaClass.java`)

Attributes:

* `String day`

* `String instructor`

---

### ✅ Class: BoxingClass (in `BoxingClass.java`)

Implements: `Schedule`

* `String day`

## 🔹 Task 2: Member Class (in `Member.java`)

Attributes:

* `String name`
* `String memberId`

---

## 🔹 Task 3: FitnessSchedule Class (in `FitnessSchedule.java`)

### Attributes:

* `Set<Schedule> classes`
* `Map<Member, Set<Schedule>> memberSchedule`

### Methods:

* `void addClass(Schedule schedule)`
* `void enrollMember(Member member, Schedule schedule)`
* `void viewMemberSchedule(Member member)`
* `void viewClassParticipants(Schedule schedule)`

---

## 🔹 Task 4: Main Method (in `FitnessSchedule.java`)

### Steps:

1. Create class objects (Yoga, Zumba, Boxing)
2. Create members
3. Create FitnessSchedule system
4. Add classes to system
5. Enroll members
6. Display schedules and participants
