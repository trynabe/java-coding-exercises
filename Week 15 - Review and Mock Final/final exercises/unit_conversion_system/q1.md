# 📝 ข้อ 1: ระบบจัดการหน่วยวัด (Unit Converter with Exception Handling)

📌 **รายละเอียดโจทย์**
สร้างระบบสำหรับการแปลงหน่วยวัดต่างๆ ได้แก่ อุณหภูมิ, ระยะทาง, และน้ำหนัก โดยระบบจะต้องมีการจัดการกับข้อผิดพลาด (Exception Handling) ในกรณีที่ผู้ใช้ป้อนข้อมูลผิดประเภท หรือป้อนค่าที่ไม่สามารถเป็นไปได้ในความเป็นจริง

---

### 📁 ไฟล์และคลาสที่ต้องสร้าง
1. `UnitConverter.java` (Class สำหรับคำนวณ)
2. `ConversionUI.java` (Class สำหรับจัดการ Input/Output และ Main Method)

---

### 🎯 สิ่งที่คุณต้องทำ (Tasks)

**Task 1: `UnitConverter.java`**
สร้างเมธอดสำหรับการแปลงหน่วย หาก Input ไม่ถูกต้องให้ `throw IllegalArgumentException` พร้อมระบุข้อความ Error:
* `celsiusToFahrenheit(double celsius)`: แปลงเซลเซียสเป็นฟาเรนไฮต์ (อุณหภูมิห้ามต่ำกว่า `-273.15`)
* `metersToFeet(double meters)`: แปลงเมตรเป็นฟุต (ระยะทางห้ามติดลบ)
* `kilogramsToPounds(double kilograms)`: แปลงกิโลกรัมเป็นปอนด์ (น้ำหนักห้ามติดลบ)

**Task 2: `ConversionUI.java`**
สร้างเมธอดสำหรับการโต้ตอบกับผู้ใช้:
* `getInput(String prompt)`: แสดงข้อความ `prompt` และรับค่าจาก `Scanner` หากผู้ใช้ใส่ข้อมูลไม่ใช่ตัวเลข ให้ `throw InputMismatchException`
* `displayResult(String result)`: แสดงผลลัพธ์การแปลงหน่วย

**Task 3: Main Method (ใน `ConversionUI.java`)**
* สร้าง Object ของ `UnitConverter` และ `ConversionUI`
* รับ Input จากผู้ใช้ (เลือกหน่วยที่ต้องการแปลง และรับค่าตัวเลข)
* ใช้ `try-catch` เพื่อดักจับ `IllegalArgumentException` และ `InputMismatchException`
* ใช้ `finally` เพื่อแสดงข้อความ `"Program execution completed."` เสมอ
